# 📝 Notes Manager

**Minimal • Offline • Customizable**

A modern desktop notes app built with **Electron & JavaScript**  
Markdown-powered, file-based, and fully customizable.

![App Demo](assets/demo.gif)

</div>

---

## ✨ Highlights

- 📝 Markdown editor with **live preview**
- 📁 Notes stored as real `.md` files
- 🔍 Fast search by title, content, and tags
- 🌗 Light / Dark mode
- 🎨 **Custom Theme Editor**
- 💾 Themes saved as JSON on Desktop
- ⚡ Auto-save, no cloud, fully offline
